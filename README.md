## 📋 نبذة عن المشروع

**لوحة تحكم حفلة** — التطبيق المكمل لمشروع [partyapp](https://github.com/Zuhairibrahim/partyapp). يدير المشرف من خلالها القاعات، مقدمي الخدمات، الحجوزات، والعملاء، مع حماية بشاشة PIN خاصة للأدمن فقط.

## 📋 About

**Party App Admin** — the companion admin dashboard for the [partyapp](https://github.com/Zuhairibrahim/partyapp) project. Manage venues, vendors, bookings, and customers — protected by a secure admin PIN screen.

## ✨ Features | المميزات

- 🔐 Secure admin PIN authentication | دخول محمي برمز PIN
- 🏛 Manage venues & halls | إدارة القاعات والصالات
- 🎪 Manage vendors & service providers | إدارة مقدمي الخدمات
- 📅 Bookings overview & follow-up | متابعة الحجوزات
- 👥 Customers management | إدارة العملاء
- 🌙 Luxury dark-gold dashboard theme | لوحة تحكم فاخرة

## 🛠 Tech Stack

`Flutter` · `Firebase` · `Material 3`

## ⬇️ Download & Run | التحميل والتشغيل

```bash
git clone https://github.com/Zuhairibrahim/partyapp_admin.git
cd partyapp_admin
flutter pub get
flutter run
```

> 🔗 Main app: [partyapp](https://github.com/Zuhairibrahim/partyapp)
